## Loop

- **State:** `tapps_memory` recall (wayfind query above) → `git status` + `gh pr view 131`
  → the sub-goal and cumulative caps from the last handoff. Re-verify live state before
  trusting any handoff claim (PR state especially — #131 could be merged or closed).
- **Decide:** lowest-numbered sub-goal whose proof is not yet pasted. If a storage
  mechanism decision appears, **stop** → `/tapps-wayfind`.
- **Execute:** the action, on the committed mechanism + tier above.
- **Verify (independent):** spawn a fresh-context `general-purpose` / `opus` verifier
  prompted to **refute** the proof. Hand it the **exact command and expected artifact**,
  never the narrative. Environment quirks it must be told: use
  `uv run python -m pytest` (bare `python3` has no pytest in this repo); Postgres is on
  **15432**, not 5432; `gh pr checks` renders *cancelled* as "fail", so read
  `.conclusion` from `gh api .../check-runs` instead. Its report must quote observed
  output. Its verdict — not the executor's claim — advances the loop.
- **On fail:** record structured handoff → scope a narrow fix sub-goal → re-execute →
  re-verify. ≤ **3** validation rounds per sub-goal, then escalate once, then stop with
  a diagnosis. Never weaken the contract to go green.
- **Record:** completed · undone · commands+exit codes · issues · failure-and-why → brain.
- **Context hygiene:** targeted `grep` over full re-`Read`; carry a compact state
  summary, not raw transcripts. Never `Read` a subagent's `.output` transcript file.
- **Print every iteration:**
  `SCORE: val=<n>/7 · acs_covered=<n>/8 · scan=<red|green> · sub-goal <k>/5 · iter <i>/12`
- **Checkpoint:** at each sub-goal boundary or ~50% context — whichever first.
- **Repeat or stop:** until Done-when holds. Caps: **12 iterations** AND **~400k tokens**,
  both **cumulative across shifts**, read from the handoff, never reset by a clear.
