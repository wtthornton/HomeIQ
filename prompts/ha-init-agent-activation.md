## Loop

- **State:** `tapps_memory` recall (this map + office-run learnings) → VAL
  coverage → git status → live audit output.
- **Decide:** lowest-numbered sub-goal whose VALs are not all green.
- **Execute:** on the committed mechanism + tier.

- **On fail:** structured handoff (done/undone/commands+exit codes/why) → narrow
  fix sub-goal → re-execute → re-verify. **≤3 rounds per sub-goal**, escalate
  once, then stop with a diagnosis. Never weaken a VAL to go green.

- **Context hygiene:** grep artifacts, never re-Read whole; carry a compact state
  summary forward.
- **Repeat or stop:** until Done-when. Caps: **15 iterations** AND **~500k tokens**.

## Guardrails

- Termination: Done-when; caps above. **Caps must not fire on correct behavior:**
  audit rows `NEEDS_APPLY`/`BLOCKED_ON_HUMAN` are findings; `integrations.zha`
  never applying on this instance is required; deleted Z2M files scoring "missing"
  is the intended outcome.
- **Never re-form the ZHA network on an instance with a loaded entry.** This is
  the one destructive trap in the whole prompt — it orphans every paired device.
- **No cognition in HomeIQ** — recipes read the manifest; only AF reasons.
- **Zero `entity_id` renames.** Additive metadata only.
- **Never write an HA payload from memory** — captured transcripts and source
  reads only; `tapps_lookup_docs`/`tapps_research` are free, use them.
- Every subagent dispatch names `agentType` + `model`; read-only steps use
  `Explore` so the tool boundary enforces it.
- No fan-out of coupled writes — SG4-SG7 serial in-session.
- **Never print the HA token or `afp_*` key. Do not read `.env*`.**
- `--env-file .env` on every single-service compose command.
- No green-by-suppression: don't relax a recipe check, skip a test, or trim the
  manifest to make a VAL pass.
- Scope: HomeIQ repo + AF project `homeiq` + live HA. Defects in AF platform or
  TappsMCP become Linear issues in *their* projects via `linear-issue`.
- **Out of scope — do not attempt:** HA core upgrade; Hue bridge pairing (blocked
  upstream, see memory); physical Zigbee device pairing (human, recorded in
  `.tapps-mcp/pending-human-actions.jsonl`); repairing any Zigbee2MQTT code.
- Discipline: root cause not workarounds; right-sized; durable; match repo
  conventions; no silent scope creep.
